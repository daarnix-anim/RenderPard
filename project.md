# Техническая Спецификация и Дорожная Карта: RenderPard

## Описание проекта
**RenderPard** — это приложение для Windows, предназначенное для быстрой и удобной пакетной конвертации медиафайлов. Основная философия: "Минимум кликов — максимум производительности". Интерфейс должен быть эстетичным, темным (Carbon Tech) и современным, а под капотом должно работать мощное ядро FFmpeg.

## 🛠 Технический Стек
* **Платформа:** .NET 10 (C#)
* **UI-фреймворк:** WPF (Windows Presentation Foundation)
* **Архитектура:** MVVM (через пакет `CommunityToolkit.Mvvm`)
* **Медиа-ядро:** FFmpeg (управляется через `FFmpegWrapper`)
* **Дополнительные библиотеки:** 
  - `H.NotifyIcon.Wpf` (для работы с системным треем)
  - `System.Text.Json` (для сохранения/чтения настроек)

## 🏗 Архитектура и Основные Модули (Логика приложения)

Проект разделен на два основных модуля: `RenderPard.Core` (бизнес-логика) и `RenderPard.UI` (интерфейс).

### 1. Ядро приложения (`RenderPard.Core`)
* **PresetManager:** Отвечает за загрузку и сохранение пользовательских пресетов в `%LOCALAPPDATA%\RenderPard\presets.json`. Встроенные пресеты создаются по умолчанию при первом запуске, но теперь удаленные встроенные пресеты не восстанавливаются принудительно.
* **FFmpegWrapper:** Класс-обертка для запуска процесса `ffmpeg.exe`. Содержит логику парсинга прогресса (высчитывание процентов из длительности) и обработки специальных флагов (например, `Alpha` для создания черно-белых масок `_mask.mp4`). Поддерживает аппаратное ускорение `h264_nvenc` и `hevc_nvenc`.
* **ContextMenuManager:** Работает с реестром Windows (`HKEY_CURRENT_USER\Software\Classes\SystemFileAssociations`). Позволяет добавлять каскадное меню со списком пресетов для всех поддерживаемых видео-форматов. В качестве иконок контекстного меню использует либо кастомные `.ico` пресетов, либо наследует иконку основного `.exe` файла.

### 2. Интерфейс (`RenderPard.UI`)
* **MVVM (Model-View-ViewModel):** 
  - `QueueViewModel`: Управляет основным окном (списком файлов, очередью рендера).
  - `SettingsViewModel`: Управляет настройками, пресетами и контекстным меню.
* **FfmpegDownloader:** При запуске приложения проверяет наличие `ffmpeg.exe` в папке программы. Если файла нет, автоматически скачивает ZIP-архив из релизов *Gyan.dev*, распаковывает и подготавливает к работе.
* **Глобальные настройки (`AppSettingsManager`):** Отвечает за сохранение поведения приложения: "Сворачивать в трей при закрытии", "Открывать папку после завершения" и выбор языка (RU/EN). Настройки хранятся в `appsettings.json`.
