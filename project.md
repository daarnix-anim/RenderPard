# Техническая Спецификация и Дорожная Карта: RenderPard

## Описание проекта
**RenderPard** — это приложение для Windows, предназначенное для быстрой и удобной пакетной конвертации медиафайлов. Основная философия: "Минимум кликов — максимум производительности". Интерфейс должен быть эстетичным, темным (Carbon Tech) и современным, а под капотом должно работать мощное ядро FFmpeg.

## 🛠 Технический Стек
* **Платформа:** .NET 10 (C#)
* **UI-фреймворк:** WPF (Windows Presentation Foundation)
* **Архитектура:** MVVM (через пакет `CommunityToolkit.Mvvm`)
* **Медиа-ядро:** FFmpeg (управляется через `FFmpegWrapper`)
* **Дополнительные библиотеки:** 
  - `H.NotifyIcon.Wpf` (для работы с системным треем)
  - `System.Text.Json` (для сохранения/чтения настроек)

## 🏗 Архитектура и Основные Модули (Логика приложения)

Проект разделен на два основных модуля: `RenderPard.Core` (бизнес-логика) и `RenderPard.UI` (интерфейс).

### 1. Ядро приложения (`RenderPard.Core`)
* **PresetManager:** Отвечает за загрузку и сохранение пользовательских пресетов в `%LOCALAPPDATA%\RenderPard\presets.json`. Встроенные пресеты создаются по умолчанию при первом запуске, но теперь удаленные встроенные пресеты не восстанавливаются принудительно.
* **FFmpegWrapper:** Класс-обертка для запуска процесса `ffmpeg.exe`. Содержит логику парсинга прогресса (высчитывание процентов из длительности) и обработки специальных флагов (например, `Alpha` для создания черно-белых масок `_mask.mp4`). Поддерживает аппаратное ускорение `h264_nvenc` и `hevc_nvenc`.
* **ContextMenuManager:** Работает с реестром Windows (`HKEY_CURRENT_USER\Software\Classes\SystemFileAssociations`). Позволяет добавлять каскадное меню со списком пресетов для всех поддерживаемых видео-форматов. В качестве иконок контекстного меню использует либо кастомные `.ico` пресетов, либо наследует иконку основного `.exe` файла.

### 2. Интерфейс (`RenderPard.UI`)
* **MVVM (Model-View-ViewModel):** 
  - `QueueViewModel`: Управляет основным окном (списком файлов, очередью рендера).
  - `SettingsViewModel`: Управляет настройками, пресетами и контекстным меню.
* **FfmpegDownloader:** При запуске приложения проверяет наличие `ffmpeg.exe` в папке программы. Если файла нет, автоматически скачивает ZIP-архив из релизов *Gyan.dev*, распаковывает и подготавливает к работе.
* **Глобальные настройки (`AppSettingsManager`):** Отвечает за сохранение поведения приложения: "Сворачивать в трей при закрытии", "Открывать папку после завершения" и выбор языка (RU/EN). Настройки хранятся в `appsettings.json`.

## 🗺 Дорожная Карта (Roadmap)

### ✅ Завершено (Фаза 1 & 2 & 3)
- [x] Разработка базового MVVM-интерфейса WPF.
- [x] Авто-скачивание и инициализация FFmpeg.
- [x] Интеграция с контекстным меню Windows (динамические подменю для видео, аудио и изображений).
- [x] Написание FFmpeg-обертки с поддержкой очередей и отмены.
- [x] Реализация работы с Alpha-каналом (отделение прозрачности в `_mask`).
- [x] Глобальный UI-редизайн: переход на стиль "Carbon Tech" с оранжевыми акцентами, кастомные чекбоксы, правильное масштабирование SVG-иконок через `ViewBox`.
- [x] Внедрение глобальных настроек (System Tray, Language, Open Folder, Subfolder creation).
- [x] Создание системы полностью кастомных пользовательских пресетов с 3 вкладками (Видео, Фото, Аудио).
- [x] **Конвертация в GIF:** Добавление пресетов и логики для качественного перекодирования видео в зацикленные GIF.
- [x] **Обработка Изображений и RAW:** Поддержка форматов (JPEG, PNG, WebP, HEIC, CR2, NEF, ARW, DNG) для сжатия и конвертации изображений.
- [x] **Конвертация Документов и Вектора:** Преобразование PDF и AI в изображения через PdfiumViewer и Magick.NET.
- [x] **Полноценный Аудио-конвертер:** Пакетная конвертация аудиофайлов (WAV, OGG, Opus, FLAC, AAC, MP3) и мгновенное извлечение звука из видеофайлов в 1 клик.
- [x] **Интерактивная обрезка и Кадрирование (Trimmer & Crop):** Встроенный плеер и таймлайн со скобками точек входа/выхода (In/Out), горячими клавишами, точным ручным вводом, Lossless-срезом и интерактивным кадрированием прямо на плеере (9:16, 16:9, 1:1, Custom).
- [x] **Сохранение иконок и настроек:** Персистентное хранилище `%AppData%\Local\RenderPard\CustomIcons\` и пак из 86 векторных иконок (Light / Dark) с адаптивным определением контраста для темы Windows.
- [x] **Авто-Обновления (Updater):** Система бесшовного автообновления самого RenderPard через GitHub Releases.
- [x] **Мультисегментная обрезка (Multi-Clip Export):** Выбор произвольного количества фрагментов, покадровая склейка в 1 файл (`concat`) и параллельный экспорт отдельными файлами (`_part1`, `_part2`).
- [x] **Расширенное аппаратное ускорение:** Поддержка Intel QuickSync (H.264, HEVC, AV1), AMD AMF (H.264, HEVC, AV1), NVIDIA NVENC (AV1, HEVC, H.264) и CPU SVT-AV1.
- [x] **Интерактивные скобки обрезки на таймлайне:** Прямой захват и перетягивание границ In `[` и Out `]` мышкой без смещения курсора воспроизведения.
- [x] **Универсальный авто-ремукс видео (DASH/YouTube):** Мгновенное устранение проблемы черного экрана при открытии фрагментированных роликов и видео без аудиодорожек за 0.3 сек.
- [x] **Якорная модель кадрирования (Crop Anchor Fix):** Идеальное масштабирование кропа из любого угла и стороны с жесткой фиксацией противоположной точки.
- [x] **Масштабируемый Premiere-style таймлайн:** Навигатор с изменяемыми границами зума и покадровым перемещением.
- [x] **Инсталлятор:** Создание удобного установщика (Inno Setup) с автоматическим версионированием имени файла `RenderPard_Setup_vX.X.X.exe`.
- [x] **Drag-and-Drop сортировка пресетов:** Перетаскивание пресетов в настройках с подсветкой линии вставки, автоматическим сохранением `SortOrder` и синхронизацией порядка в контекстном меню Windows.
