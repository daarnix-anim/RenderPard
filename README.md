# RenderPard

**RenderPard** — это современная, быстрая и удобная программа для пакетного кодирования и обработки видео на Windows, созданная для оптимизации рабочих процессов с медиафайлами.

## 🚀 Основные возможности

* **Аппаратное ускорение (NVENC):** Максимально быстрое кодирование видео с использованием видеокарт NVIDIA (H.264 и H.265/HEVC).
* **Пользовательские пресеты:** Полная свобода в создании, редактировании и удалении собственных пресетов кодирования. Настраивайте кодеки, параметры аудио и видео, добавляйте водяные знаки, выбирайте собственные иконки для пресетов — всё в современном и эргономичном интерфейсе.
* **Продвинутая логика нумерации:** Выбирайте, где и как добавлять нумерацию к пакетно-обрабатываемым файлам (суффикс, префикс, без изменений с умным распознаванием коллизий).
* **Широкая поддержка форматов:** Конвертируйте видео, изображения (включая RAW-форматы: CR2, NEF, ARW, DNG, и HEIC от Apple iPhone), а также извлекайте текст из PDF-файлов. Встроены стандартные пресеты для конвертации изображений в JPEG и WebP.
* **Интеграция с Windows:** Добавляйте ваши любимые пресеты прямо в контекстное меню системы. Выделяйте нужные файлы и запускайте кодирование в один клик правой кнопкой мыши без открытия основного окна. Регистрация меню происходит автоматически при запуске приложения.
* **Работа с Alpha-каналом:** Функция разделения видео с прозрачностью (например, ProRes 4444) на два файла: основное видео и черно-белую маску (`_mask.mp4`). Идеально подходит для интеграции видео в веб-дизайн.
* **Конвертация в GIF:** Высококачественное преобразование видео в зацикленные GIF-анимации с настройкой частоты кадров.
* **Наложение водяных знаков:** Гибкая система добавления текстовых водяных знаков с настройкой шрифта, размера, прозрачности, отступов и позиционирования (по углам или по центру).
* **Удобная очередь задач и Drag-and-Drop:** Перетаскивайте файлы прямо в главное окно и выбирайте нужный пресет во всплывающем меню! Управляйте списком задач, приостанавливайте или отменяйте рендер.
* **Глобальные настройки и Трей:** Возможность закрепить окно поверх всех окон (Always on Top), сворачивать программу в системный трей, автоматически открывать папку после завершения обработки и менять язык интерфейса (RU/EN) на лету.
* **Автоматическая загрузка FFmpeg:** Программа не требует ручной установки сторонних кодеков — при первом запуске она сама скачает актуальную версию ядра FFmpeg.
* **Облачные авто-обновления:** Бесшовное фоновое обновление. Приложение проверяет новые версии на GitHub и обновляется в один клик.

## 📝 История версий

### Версия 1.4.5
* **Обновленная панель пресетов:** 
  * Разделение списка пресетов на вкладки **«Видео»** и **«Фото»** для мгновенной навигации.
  * Сдержанные минималистичные кнопки **«➕ Добавить»** и **«✕ Удалить»** в стиле Ghost Carbon.
  * Строки пресетов с аккуратным многоточием и иконками слева, флажками контекстного меню справа.
* **Расширенные настройки аудио для видео:**
  * Полноценный выбор режима аудио: **Копировать оригинал**, **Перекодировать** или **Без звука** (`-an`).
  * Гибкая настройка кодека (AAC, MP3, Opus, PCM 24-bit), битрейта, частоты дискретизации (48 kHz / 44.1 kHz) и каналов (Стерео / Моно).
  * Выравнивание громкости под стандарты стриминга (-14 LUFS для YouTube / Reels / TikTok).
* **Ультратонкие ползунки прокрутки (Scrollbars):**
  * Полностью переработаны полосы прокрутки во всех окнах (толщина всего 4 px, без пустых отступов и устаревших стрелок).
* **Полная ревизия локализации:**
  * Безупречный перевод всех выпадающих списков, параметров и подсказок на русский и английский языки.
