# RenderPard

**RenderPard** — это современная, быстрая и удобная программа для пакетного кодирования и обработки видео на Windows, созданная для оптимизации рабочих процессов с медиафайлами.

## 🚀 Основные возможности

* **Аппаратное ускорение (NVENC):** Максимально быстрое кодирование видео с использованием видеокарт NVIDIA (H.264 и H.265/HEVC).
* **Работа с Alpha-каналом:** Уникальная функция разделения видео с прозрачностью (например, ProRes 4444) на два файла: основное видео и черно-белую маску (`_mask.mp4`). Идеально подходит для веб-разработки и сайтов.
* **Наложение водяных знаков:** Гибкая система добавления текстовых водяных знаков (ватермарок) с настройкой шрифта, размера, прозрачности, отступов и позиционирования (по углам или по центру).
* **Удобная очередь задач:** Поддержка Drag-and-Drop. Перетаскивайте файлы прямо в окно программы, управляйте очередью, удаляйте задачи или очищайте весь список в один клик.
* **Интеграция с Windows:** Программа встраивается в контекстное меню. Достаточно кликнуть правой кнопкой мыши по любому видеофайлу и выбрать «Кодировать в RenderPard».
* **Автоматическая загрузка FFmpeg:** Программа не требует сторонних кодеков — при первом запуске она сама скачает актуальную версию ядра FFmpeg.
* **Облачные авто-обновления:** Бесшовное фоновое обновление. Приложение автоматически проверяет новые версии на GitHub и может обновиться в один клик без перехода в браузер.

## 🛠 Технологии
Приложение написано на **C# (.NET 10)** с использованием **WPF** и паттерна **MVVM**. В качестве движка обработки медиа под капотом используется мощь **FFmpeg**.
